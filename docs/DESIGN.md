# Design brief

登壇・取材の依頼者、研究や技術活動に関心を持つ人が、人物像と実績を一度に確認できる1ページ。

## Structure

名前と写真 → 活動領域 → 略歴 → 経歴 → 研究・特許 → 書籍・執筆 → 登壇 → 取材 → 公共活動・資格 → 関心・連絡先。

主な導線は、人物像を読んで連絡する、研究の原典を開く、登壇や執筆の履歴を調べる、の3つ。

## Visual system

DADSのNoto Sans JP、ニュートラル色、ブルー1色。文字サイズ・行間・コンポーネントは同梱のDADSを使用。白地に細い罫線と余白で区切る。小さい写真と日本語名を隣接させ、冒頭をコンパクトにまとめる。所属・目次・略歴の始まりまでPCの最初の画面内に収め、情報の密度を保つ。装飾の数字・カードの羅列は使わない。

PCはセクション見出しと本文の2列、スマートフォンは1列。全実績を最初から一覧表示する。折り畳み・タブ・絞り込みで件数を隠さず、量そのものを伝える。登壇は年別の見出しと罫線で区切る。書籍と研究はすぐ見える位置に置く。内容はすべて初期HTMLに含める。

## Validation

原稿内の項目とリンクの保存、スマートフォンの横溢れ、PCでの行長、アンカーの操作、JavaScript無効時の本文、印刷時の全件表示を確認する。
